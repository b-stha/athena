# Branch workflow

Before starting a new task, inspect the working tree and existing local and
remote branches for related work. Reuse a suitable active branch rather than
creating a separate branch for every task.

Create a new branch only when no suitable related branch exists or the user
explicitly requests a separate branch. Preserve unrelated uncommitted changes.
Before deleting a branch, verify that its commits are preserved in the retained
branch. Keep commit messages short, lowercase, and imperative.
